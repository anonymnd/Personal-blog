هاد الأمثلة غير باش نفهمو الفكرة؛ الإعدادات ديال التطبيق وبعض التعريفات المساعدة ممكن ما يكونوش مكتوبين.

تخايل معايا عندك قاعدة بيانات (database) خدامة وسط Docker container. جربتي تكونيكطا ليها بـ `localhost:5432` من الماكينة ديالك، ولكن لقيتي connection refused. وخا الداتابيز خدامة مزيان لداخل، راها محبوسة فواحد الشبكة معزولة. الكونتينر بحال شي بيت مسدود، و Port Mapping هو لي كايصاوب لينا باب باش ندخلو من الماكينة ديالنا لداك البيت.

## كيفاش خدامة هاد العملية
فالأصل، كل كونتينر عندو IP و ports ديالو لداخل. ولكن المتصفح (browser) ديالك كيهضر مع السيستيم ديال البي سي (host). Port mapping كايقول لـ Docker: "أي حاجة جات للبي سي فالبورت X، صيفطها للكونتينر فالبورت Y". هادشي كيتكتب على شكل `host_port:container_port`. خاصك تعرف بلي `localhost` ديال الكونتينر ماشي هو `localhost` ديال الماكينة ديالك.

## مثال تطبيقي: تطبيق ديال المشتريات (Procurement App)
نفترضو عندك تطبيق ديال المشتريات فين الموظف كيدفع طلب. الـ backend خدام فالبورت 8080 لداخل ديال الكونتينر، ولكن نتا بغيتي تدخل ليه من البي سي ديالك عبر البورت 9000 باش ما يوقعش تضارب مع برامج أخرى.

```bash
# كنربطو البورت 9000 ديال الماكينة مع 8080 ديال الكونتينر
docker run -p 9000:8080 procurement-backend
```

**النتيجة:** ملي كتمشي لـ `http://localhost:9000` فالمتصفح، Docker كيشد داك الطلب وكيصيفطو للبورت 8080 لداخل ديال الكونتينر. التطبيق كيعالج الطلب وكيرجع الجواب عبر نفس الطريق.

## غلط شائع: تقليب الترتيب
بزاف ديال المبتدئين كيقلبو لي بورت، مثلا كيكتبو `-p 8080:9000` وخا التطبيق لداخل راه خدام فـ 8080.

**التصحيح:** ديما عقل على القاعدة `الخارجي:الداخلي`. إلا كان التطبيق ديالك (مثلا Spring Boot) خدام فـ `server.port=8080` ، الرقم التاني فـ mapping خاصو يكون 8080.

## التواصل بين الكونتينرات
إلا كان عندك جوج خدمات (services) فـ Docker Compose، مثلا خدمة ديال manager وخدمة ديال buyer، راه ما كيحتاجوش port mapping باش يهضرو بيناتهم. كيستعملو السمية ديال الخدمة والبورت الداخلي. مثلا، الـ manager كيوصل للـ buyer عبر `http://buyer:8080` بلا ما يدوز من الشبكة ديال البي سي.

## تمرين تطبيقي
عندك كونتينر ديال PostgreSQL خدام فالبورت 5432 لداخل. بغيتي تكونيكطا ليه من البي سي ديالك باستعمال البورت 5332. شنو هو الـ flag لي خاصك تزيد فـ docker run؟

**الجواب:** `-p 5332:5432`
