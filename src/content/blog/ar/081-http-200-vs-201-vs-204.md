هاد الأمثلة غير باش نفهمو الفكرة؛ الإعدادات ديال التطبيق وبعض التعريفات المساعدة ممكن ما يكونوش مكتوبين.

تخايل راسك خدام على تطبيق ديال الشراء (procurement system). واحد الموظف كيصيفط طلب شراء، و API ديالك كترجع ليه بلي العملية نجحات. ولكن واش هاد 'النجاح' كيعني بلي الطلب غير وصل، ولا بلي تكريا سجل جديد، ولا بلي وقع تحديث بلا ما نحتاجو نصيفطو البيانات؟ يلا بقيتي كتستعمل غير 200 OK لكلشي، الـ frontend غادي يلقى صعوبة باش يعرف واش خاصو يدير redirection للمستخدم ولا غير يـ refresh-ي الليستة.

## شنو هو HTTP 200 OK
HTTP 200 هو الكود العادي ملي كتكون الطلبية دازت بنجاح. غالباً كنستعملوه مع GET باش نرجعو معلومات شي حاجة، ولا مع PUT/PATCH ملي السيرفر كيرجع لينا l'objet اللي تبدل. المعنى ديالو هو: "راني عالجت الطلب ديالك، وها هي النتيجة."

## الفرق في HTTP 201 Created
بينما 200 كتعني 'OK'، 201 كتعني بالضبط 'Created' (تكرى). هادي كنستعملوها بزاف مع POST. ملي الموظف كيصيفط طلب شراء جديد، السيرفر ما كيقولش غير OK، بل كيأكد بلي كاين سجل جديد دابا. ومن الأحسن، الـ 201 تكون معاها `Location` header اللي كتعطي الرابط ديال هاد السجل الجديد.

## السكات ديال HTTP 204 No Content
HTTP 204 كنستعملوه ملي الطلب كيدوز بنجاح، ولكن ما كاين حتى شي حاجة باش نرجعوها للكليان في الـ body. هادشي كيوقع بزاف مع DELETE ولا ملي كانديرو update بـ PUT والكليان ديجا عندو المعلومات، دونك ما كاين لاش السيرفر يعاود يصيفط نفس الـ object. هادشي كيقتصد في الـ bandwidth.

## مثال تطبيقي: نظام المشتريات

| العملية | Method | الكود المتوقع | السبب |
| :--- | :--- | :--- | :--- |
| شوف الطلب | GET | 200 OK | كيرجع تفاصيل الطلب |
| صيفط طلب | POST | 201 Created | تكريا سجل جديد |
| بدل الحالة | PATCH | 204 No Content | تبدلات الحالة، بلا body |

```http
POST /api/purchase-requests
Content-Type: application/json

{"item": "Laptop", "qty": 1}

HTTP/1.1 201 Created
Location: /api/purchase-requests/123
```

## غلط شائع: استعمال 200 OK في كلشي
بزاف ديال المطورين كيديرو 200 OK لكلشي. مثلاً، كيرجعو 200 مورا ما يتكريا شي سجل بـ POST عوض 201. هادشي كيخلي الـ client يضطر يحلل الـ body باش يعرف واش بصح تكريات الحاجة، عوض ما يعتمد على المعنى ديال الكود HTTP.

## تمرين تطبيقي
أنا كود خاص يرجع ملي المدير كيدير 'Approve' لشي طلب، يلا كانت الـ API كتبدل الحالة لـ 'Approved' ولكن ما كترجعش l'objet في الـ body؟

**الجواب:** 204 No Content.
