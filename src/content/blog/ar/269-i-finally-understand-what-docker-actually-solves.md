تخيل معايا خدام على تطبيق ديال المشتريات (procurement app) فين الموظف كايصيفط طلب شراء. صاوبتي هادشي بـ Java 17 و PostgreSQL فـ البيسي ديالك وكلشي خدام ناضي. ولكن ملي صيفطتي الكود للمدير ديالك باش يشوفو أو حطيتيه فـ السيرفر، كلشي وقف حيت السيرفر فيه Java 11 أو شي مكتبة (library) ناقصة. هاد المشكل هو اللي كنسميوه 'خدام عندي في البيسي' (it works on my machine).

## وهم ديال التثبيت (Installation)
قبل Docker، كنا كنعتمدو على ملفات README أو سكريبتات ديال التثبيت. كنا كنتسناو أن الشخص الآخر يكون عندو نفس نسخة الويندوز أو لينيكس، ونفس الإعدادات. المشكل هو أن البرامج ماشي غير كود، بل هي بيئة كاملة. إلا تبدلات غير حاجة بسيطة فـ السيستيم، التطبيق ما كايخدمش.

## كيفاش Docker كايحل هادشي
Docker ماشي غير كايشغل التطبيق، بل كايجمع كاع داكشي اللي محتاج التطبيق باش يخدم فـ واحد الباكيج. تخيلو بحال شي 'صورة' (Snapshot) ديال بيسي فيه غير داكشي اللي ضروري. بلاصة ما تقول لصاحبك 'ثبت Java و Postgres'، كتعطيه Image. هاد الـ Image هي قالب واجد كايضمن أن البيئة غاتكون هي هي، سواء كانت فـ Mac، Windows أو سيرفر Linux.

## مثال تطبيقي ديال تطبيق المشتريات
باش نخدمو التطبيق ديالنا، خاصنا JDK و قاعدة بيانات. بلاصة ما نثبتوهم بيدينا، كنستعملو `Dockerfile`:

```dockerfile
FROM eclipse-temurin:17-jdk-alpine
COPY target/procurement-app.jar app.jar
ENTRYPOINT ["java", "-jar", "/app.jar"]
```

ملي المدير كايخدم هاد الـ container، Docker كايصاوب ليه بيئة معزولة. التطبيق ما كايشوفش السيستيم ديال المدير، بل كايشوف غير Alpine Linux اللي حددنا فـ الـ Image. النتيجة هي أن التطبيق غايخدم عند كلشي بنفس الطريقة.

## غلط شائع: تجميع كلشي فـ Image وحدة
بزاف ديال المبتدئين كايحاولو يديرو كلشي (قاعدة البيانات، الكاش، والتطبيق) فـ Image وحدة. هادشي غلط حيت كايثقل الخدمة. الحل هو دير كل خدمة فـ container بوحدو (واحد للتطبيق وواحد لـ PostgreSQL) وتربط بيناتهم بـ network.

## تمرين تطبيقي
إلا كان عندك مشروع محتاج Python 3.9 ومكتبة `requests` ولكن السيرفر فيه غير Python 3.6، كيفاش Docker كايحل هاد المشكل بلا ما تبدل النسخة ديال Python اللي فـ السيرفر كامل؟

**الجواب:** كاتصاوب Image Docker مبنية على `python:3.9-slim`. التطبيق غايخدم وسط الـ container بالنسخة 3.9 ديالو، وما غايسوقش للنسخة 3.6 اللي كاينه فـ السيرفر.
