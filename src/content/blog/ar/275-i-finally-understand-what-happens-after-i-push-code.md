بزاف دالوقت كنت كيسحاب لي `git push` غير بوطون سحرية كتهز الكود من البي سي ديالي وكتحطو فالسيرفر. مكانش كيبان لي داك الجسر اللي كاين بين فين كنكتب الكود وبين التطبيق اللي خدام فعلياً. فهمت هادشي ملي حبست نشوفها كأنها 'صيفطت ملفات' وبديت نشوفها كأنها 'ساروت' كيخدم واحد السلسلة ديال العمليات (Pipeline).

## التسليم للمستودع البعيد (Remote Repository)
ملي كدير push، راك ماشي كتصيفط التطبيق للسيرفر، ولكن كتصيفط commits لواحد النظام ديال تتبع النسخ (VCS) بحال GitHub. هاد النظام كيكون هو المرجع الأساسي، ولكن ما كيخدمش الكود، غير كيخزنو. الخدمة كتبدا ملي GitHub كيعلم واحد الأداة ديال CI/CD بلي كاين كود جديد.

## مرحلة البناء والتجريب (Build and Test)
ملي السيرفر ديال CI (Continuous Integration) كيشوف الـ push، كيخدم pipeline. كيهز الكود لواحد البيئة معزولة (غالباً Docker container) وكيجرب واش كيتبنى (Build) مزيان، مثلاً باستعمال `./mvnw clean package`. هنا كيتأكدوا بلي الكود مافيهش أخطاء فالتجميع وبلي tests كاملين دازو. إلا كان شي خطأ، العملية كتحبس تما باش الكود الخاسر ما يوصلش للمستخدم.

## التغليف والنشر (Packaging and Deployment)
إلا داز الـ build بنجاح، الكود كيتحول لـ artifact، اللي هو غالباً Image Docker. هاد الـ image فيها الكود مجمّع والبيئة اللي محتاج باش يخدم. هاد الـ image كتمشي لواحد الـ Registry. من بعد، أداة الـ CD (Continuous Deployment) كتقول للسيرفر (بحال Kubernetes) باش يهز الـ image الجديدة ويبدل بها القديمة.

## مثال تطبيقي: تطبيق ديال المشتريات
تخيل تطبيق ديال المشتريات فين الموظف كيصيفط طلب شراء. أنا بدلت `RequestService.java` باش نزيد واحد التحقق (validation).
1. **Push**: صيفطت التغيير لـ GitHub.
2. **CI**: Jenkins جرب واش هاد التحقق ما خسرش عملية الموافقة ديال المدير.
3. **CD**: الـ image الجديدة تحطات فالسيرفر.
4. **النتيجة**: دابا التطبيق ولا كيرفض الطلبات اللي مافيهمش وصف.

## غلط شائع: خلط Git مع Deployment
بزاف كيسحاب ليهم بلي `git push` هي نيتها Deployment. إلا صيفطتي الكود لشي branch ما مرتبطةش بـ pipeline، الكود غادي يتسيفط لـ GitHub ولكن التطبيق اللي خدام ما غادي يتبدل فيه والو. ديما شوف حالة الـ pipeline ماشي غير الـ git history.

## تمرين تطبيقي
إلا وقع مشكل (fail) فمرحلة الـ 'Test' فـ pipeline، واش التطبيق اللي خدام عند الناس غادي يتحدث للنسخة الجديدة؟

**الجواب**: لا. الـ pipeline كيوقف تما باش يحمي التطبيق من أنه يطيح بسباب شي bug.
