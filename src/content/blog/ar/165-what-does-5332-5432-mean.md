هاد الأمثلة غير باش نفهمو الفكرة؛ الإعدادات ديال التطبيق وبعض التعريفات المساعدة ممكن ما يكونوش مكتوبين.

تخيل معايا يلاه طلقتي container ديال PostgreSQL باستعمال Docker. جيتي تبغي تكونيكطي Database GUI لـ `localhost:5432` ولكن عطاك 'Connection Refused'، وخا الـ logs كيقولو بلي كلشي خدام مزيان. المشكل هنا غالبا كيكون حيت ما فهمناش مزيان هاديك `-p 5332:5432`.

## الفرق بين الـ Host والـ Container
الـ containers ديال Docker كيكونوا معزولين فـ network namespace ديالهم. هادشي كيعني بلي الـ container عندو IP ديالو بوحدو والبورتات ديالو بوحدهم. إلا كانت database وسط container كتسنى فالبورت 5432، راه كتسنى فـ localhost ديال الـ container، ماشي ديال البي سي ديالك. باش توصل ليها من برا، خاصك دير واحد القنطرة (bridge).

## كيفاش نقراو هاد السنتَاكس
القاعدة هي `host_port:container_port`. فالمثال ديالنا `5332:5432`:
- **5332 (Host Port):** هادا هو البورت اللي كتحلو فالمكينة ديالك (البي سي). ملي كتقول للتطبيق كونيكطى لـ `localhost:5332` ، Docker كيشد داك الترافيك.
- **5432 (Container Port):** هادا هو البورت اللي التطبيق خدام بيه لداخل وسط الـ container. Docker كياخد داك الترافيك من 5332 وكيصيفطو لـ 5432 لداخل.

## مثال تطبيقي: تطبيق ديال المشتريات (Procurement)
تخيل عندنا سيستيم ديال المشتريات، فيه `request-service` خاصو يسجل المعلومات فـ PostgreSQL container. فـ `docker-compose.yml` كنكتبو:

```yaml
services:
  db:
    image: postgres
    ports:
      - "5332:5432"
```

**النتيجة:**
1. إلا بغيتي تدخل لـ DB من pgAdmin فـ البي سي ديالك، غتخدم بـ `localhost:5332`.
2. إلا كان container آخر فـ نفس الشبكة بغا يهضر مع الـ DB، غيخدم بسمية السيرفيس `db:5432` (هنا ما كيهمناش البورت ديال الـ host).

## غلط شائع: تقليب الترتيب
بزاف كيغلطو وكيكتبو `5432:5332`. هنا Docker كيصحاب ليه بلي خاصو ياخد الترافيك من البورت 5432 ديال البي سي ويصيفطو لـ 5332 لداخل. وبما أن PostgreSQL خدام فـ 5432 لداخل، الكونيكسيون غتفشل حيت ما كاين حتى حاجة كتسنى فـ 5332 لداخل.

## تمرين تطبيقي
إلا بغيتي تخدم web server اللي كيخدم لداخل فالبورت 80، ولكن البي سي ديالك ديجا فيه موقع خدام فالبورت 80، كيفاش غدير للمابينغ (mapping) باش تدخل ليه من `localhost:8080` ؟

**الجواب:** خاصك تخدم بـ `-p 8080:80`.
