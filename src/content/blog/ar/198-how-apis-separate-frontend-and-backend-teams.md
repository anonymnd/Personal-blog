تخيل معايا واحد الموقف فين الديفلوبور ديال الـ frontend كيتسنى الديفلوبور ديال الـ backend حتى يسالي واحد الجدول في لاباز دو دوني (database) عاد يقدر يبدا يصاوب غير فورم (form) ديال التسجيل. هاد التبعية كتعطل المشروع كامل. الحل هنا هو الـ API، اللي كيخدم بحال شي عقد رسمي بين الجوج جواه.

## الـ API بحال شي عقد
الـ API كايحدد بالضبط شنو هي المعلومات اللي يقدر يطلب الـ frontend وشنو غادي يجاوب الـ backend. بلا ما يحتاج الـ frontend يعرف كيفاش مصاوبة لاباز دو دوني ولا أما لغة مستعملة في السيرفر، كيهمو غير الـ 'endpoint' (الرابط) والـ 'payload' (المعلومات اللي كتكون JSON). هادشي كيخلي الفرق يخدمو في دقة وحدة: غير كيتفقو على العقد، الـ frontend كيبدا يخدم ببيانات وهمية (mock data) والـ backend كيبني المنطق الحقيقي.

## فصل الهندسة (Decoupling)
في الخدمة ديال دابا، الـ frontend (اللي خدام في المتصفح) والـ backend (اللي خدام في السيرفر) كيكونوا مفروقين. الـ frontend مكلف بالشكل وكيفاش كيتفاعل المستخدم، والـ backend مكلف بالقواعد ديال البيزنس وتخزين البيانات. كيهضرو مع بعضياتهم بـ HTTP. حيت مفروقين، تقدر تبدل الـ frontend كامل بـ framework جديد بلا ما تقيس حتى سطر في الـ backend، مادام الـ endpoints ديال الـ API بقاو هما هما.

## مثال تطبيقي: تطبيق ديال المشتريات
تخيل تطبيق فين الموظف كيصيفط طلب شراء.

**العقد:**
- **الرابط:** `POST /requests`
- **المعلومات المرسلة:** `{"item": "Laptop", "quantity": 1}`
- **الجواب:** `201 Created` مع `{"id": 101, "status": "pending"}`

الديفلوبور ديال الـ frontend كيصاوب الفورم وكيصيفط هاد الـ JSON. وفي نفس الوقت، الديفلوبور ديال الـ backend كيصاوب الكود اللي كيسجل الطلب في لاباز وكيصيفط إشعار للمدير. حتى واحد فيهم ما محتاج يشوف الكود ديال لآخر باش تخدم الميزة.

## غلط شائع: خلط الـ CORS مع السيكوريتي
بزاف كيصحاب ليهم بلي الـ CORS هو أداة باش نحبسو الهاكرز. في الحقيقة، الـ CORS هو قانون كيطبقو المتصفح (browser) باش يمنع frontend في `app.com` يقرأ بيانات من `api.com` إلا إذا السيرفر سمح ليه. هادشي ما كيعوضش الـ authorization في السيرفر؛ ضروري خاصك تأكد واش المستخدم عندو الحق يشوف ديك البيانات في السيرفر نيت.

## تمرين تطبيقي
إلا فريق الـ backend بدل سمية واحد الحقل من `user_name` لـ `full_name` في الجواب ديال الـ API بلا ما يعلم فريق الـ frontend، شنو غادي يوقع؟

**الجواب:** الـ frontend غادي يبان فيه 'undefined' أو يوقع مشكل (crash) حيت غادي يقلب على `user_name` اللي مابقاتش، وهادشي كيعني أن العقد ديال الـ API تهرس.
