هاد الأمثلة غير باش نفهمو الفكرة؛ الإعدادات ديال التطبيق وبعض التعريفات المساعدة ممكن ما يكونوش مكتوبين.

بزاف ديال الوقت وأنا كنتلف مع ديك `-p 8080:80`. كنت كنقول مع راسي: إلا كانت l'application خدامة فالبورت 80 داخل الكونتينر، علاش خاصني بورت آخر فالمكينة ديالي؟ كنت كنحسابها غير تعقيد زايد حتى فهمت بلي Docker container ماشي غير process عادي، ولكن بحال شي ريزو (Network) صغير ومعزول عندو IP ديالو بوحدو.

## فكرة الريزو المعزول
تخيل معايا Docker container بحال شي برطمة صغيرة مسدودة. داخل هاد البرطمة، l'application (مثلا web server) كتسنى الطلبات فواحد الباب محدد، لي هو الـ container port. ولكن هاد البرطمة كاينة وسط عمارة مسدودة (لي هي Docker Host). الناس لي برا العمارة ما كيشوفوش بيبان البرطمانات، كيشوفو غير الباب الكبير ديال العمارة. باش تخلي شي حد يدخل، خاصك تدير واحد القنطرة (Tunnel) من باب محدد فالعمارة لباب محدد فالبرطمة.

## بورت الماكينة (Host) وبورت الكونتينر
فالكوموند `docker run -p 8080:80` الرقم لي على اليسار (8080) هو الـ **Host Port**، والرقم لي على اليمين (80) هو الـ **Container Port**. بورت الماكينة هو الباب لي كيشوفوه الناس من برا، وبورت الكونتينر هو فين كاين التطبيق لداخل فالعزلة ديالو.

## مثال بتطبيق ديال المشتريات (Procurement App)
تخيل عندنا سيستيم ديال المشتريات فيه `request-service` فين الموظف كيدفع طلب. لداخل ديال الكونتينر، Spring Boot مريكل يخدم فالبورت 8080. باش Manager يقدر يدخل ليه من المتصفح ديال الماكينة، كنديرو هاد الربط:

```bash
# كنربطو بورت الماكينة 9000 مع بورت الكونتينر 8080
docker run -p 9000:8080 procurement-request-app
```
دابا، ملي Manager كيدخل لـ `http://localhost:9000` ، Docker كيشد داك trafik وكيدوزو للبورت `8080` لداخل ديال الكونتينر. l'application ما كتعرفش بلي الناس من برا خدامين بـ 9000.

## غلط شائع: قلبان البورتات
واحد الغلط كيديروه بزاف هو كيقلبو الترتيب: كيديرو `-p 80:8080` وهوما بغاو `-p 8080:80`. إلا كان التطبيق ديالك كيسمع فالبورت 80 ودرتي `80:8080` ، الطلب غيوصل للماكينة فـ 80، وغيمشي للكونتينر فـ 8080، تما مالقا حتى حاجة خدامة، وغاتطلع ليك "Connection Refused".

## تمرين تطبيقي
إلا كان عندك كونتينر ديال Database خدام فالبورت 5432 لداخل، ولكن ديجا عندك PostgreSQL منصبة فالمكينة ديالك وخدامة فـ 5432، شنو هي الكوموند لي تخليك تدخل لـ DB ديال الكونتينر باستعمال البورت 5433؟

**الجواب:** `docker run -p 5433:5432 postgres`
