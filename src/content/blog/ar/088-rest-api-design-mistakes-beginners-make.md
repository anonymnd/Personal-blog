تخايل راسك خدام على تطبيق ديال الشراء (procurement system). صاوبتي واحد الـ endpoint سميتو `/updateRequest` كيخدم بـ POST باش تبدل الحالة ديال طلب شراء. واخا هادشي خدام، ولكن المطورين اللي معاك فالفريق تالفين حيت ما متبعش القواعد ديال REST. هادي هي الغلطة اللي كيديرو بزاف ديال المبتدئين: كيتعاملو مع API بحال إلا كيعيطو لـ functions عادية ماشي كيتعاملو مع resources.

## الغلط فاستعمال HTTP Methods
بزاف كيديرو POST لكلشي. فالتطبيق ديالنا، إلا بغيتي تبدل الطلب كامل، خاصك تستعمل PUT. وإلا بغيتي تبدل غير الحالة (status) من 'Pending' لـ 'Approved'، هنا PATCH هي اللي صحيحة. وعقل بلي GET خاصها تكون safe و idempotent، يعني ما خاصهاش تبدل حتى حاجة فالسيرفر.

## الفرق بين 401 و 403
المبتدئين كيخلطو بيناتهم وكيديرو 401 لأي مشكل ديال الصلاحيات. 401 كتعني أن المستخدم ما معرفش (ما دايرش login). ولكن إلا كان المستخدم معروف ولكن بغا يـ-approuver الطلب ديالو راسو (وهادشي خاص يديرو غير manager)، هنا خاص السيرفر يرجع 403 Forbidden. يعني راك معروف ولكن ما عندكش الحق.

## تجاهل الـ Status Codes الصحيحة
ما تبقاش ترجع 200 OK فكلشي. فاش شي واحد كيصيفط طلب شراء جديد، الـ API خاصها ترجع 201 Created ومعاها `Location` header فين كاين هاد الطلب. وإلا كان الطلب تقبل ولكن مازال ما تسالا المعالجة ديالو، كنستعملو 202 Accepted.

## مشكل الـ Idempotency
كاين اللي كيسحاب ليه بلي idempotent كتعني أن الـ response خاصها تكون ديما هي هي. ولكن الحقيقة هي أن الحالة ديال السيرفر هي اللي خاصها تبقى هي هي. مثلا، إلا درتي DELETE لشي طلب جوج مرات، فالمرا بجوج الطلب غيكون ممسوح، واخا المرة الأولى ترجع 204 No Content والمرة الثانية ترجع 404 Not Found.

## مثال تطبيقي: تحديث طلب شراء
**طريقة غلط:**
`POST /changeStatus?id=123&status=Approved` $ightarrow$ كترجع 200 OK

**طريقة صحيحة:**
`PATCH /requests/123` مع body فيه `{"status": "Approved"}` $ightarrow$ كترجع 200 OK مع الـ object اللي تبدل.

**غلط شائع:** تستعمل PUT باش تبدل غير حاجة وحدة.
**التصحيح:** PUT كتعوض الـ resource كاملة. إلا صيفطتي غير الـ status بـ PUT، تقدر تمسح سميت اللي طلب والشروط الأخرى بلا ما تحس.

## تمرين تطبيقي
أنا status code خاصك ترجع إلا حاول شي واحد يصاوب طلب شراء اللي فيه conflict مع شي طلب قديم (مثلا نفس رقم المرجع)؟

**الجواب:** 409 Conflict.
