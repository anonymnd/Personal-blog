You have just run `mvn test` on a large project. The console shows a few failures, but the stack trace is truncated, and you cannot tell exactly which assertion failed or why. You know the tests ran, but you don't know where the detailed reports are stored on your disk.

## The Default Output Directory
By default, Maven places all build artifacts in the `target` folder. This directory is temporary; running `mvn clean` will delete it entirely. Test reports are not stored in your source folders because they are generated results, not source code.

## Surefire vs. Failsafe Reports
Maven uses two different plugins depending on the type of test being executed. It is crucial to know which one you are using to find the right folder:

| Plugin | Test Type | Report Location |
| :--- | :--- | :--- |
| Maven Surefire | Unit Tests | `target/surefire-reports` |
| Maven Failsafe | Integration Tests | `target/failsafe-reports` |

Surefire runs during the `test` phase. Failsafe runs during the `integration-test` and `verify` phases. If you only run `mvn test`, the `failsafe-reports` folder will likely be empty or non-existent.

## Worked Example: Procurement App Tests
Imagine a procurement system where a `RequestService` ensures a requester cannot approve their own request. You write a test case `testSelfApprovalFails()`. When you run `mvn test`, the console says `Tests run: 10, Failures: 1`.

To find the details, navigate to:
`your-project/target/surefire-reports/com.procurement.RequestServiceTest.txt`

Inside this text file, you will find the full stack trace, including the `Caused by:` section, which points to the exact line in your Java code where the `AssertionError` occurred.

## Common Mistake: Searching in the Wrong Phase
A common error is running `mvn package` and wondering why integration tests didn't report failures. While `package` executes the `test` phase, it does not automatically execute the `verify` phase where Failsafe reports are finalized. To ensure integration reports are generated, use `mvn verify`.

## Practical Exercise
If you run `mvn verify` and a complex integration test for the procurement buyer module fails, which specific directory should you check for the detailed report?

**Answer:** `target/failsafe-reports`
